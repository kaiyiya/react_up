     │      └─ reconcileChildren → 创建 div Fiber
     │      └─ return div Fiber
     │

## 阶段六：Flags 冒泡 (bubbleProperties)

### 📊 Flags 收集过程

```
完成 text Fiber
  flags: Placement (0b0000010)
  subtreeFlags: NoFlags (0b0000000)
     │
     ↓ bubbleProperties
完成 div Fiber
  flags: NoFlags
  subtreeFlags: Placement (从 text 冒泡上来)
     │
     ↓ bubbleProperties
完成 HostRoot Fiber
  flags: NoFlags
  subtreeFlags: Placement (从 div 冒泡上来)
```

**关键代码**：
```typescript
// completeWork.ts:85-97
function bubbleProperties(workInProgress: FiberNode) {
    let subtreeFlags = NoFlags;
    let child = workInProgress.child;
    while (child !== null) {
        subtreeFlags |= child.subtreeFlags;  // 收集子树的 flags
        subtreeFlags |= child.flags;         // 收集子节点的 flags
        child = child.sibling;
    }
    workInProgress.subtreeFlags = subtreeFlags;
}
```

## 阶段八：提交副作用 (commitMutationEffects)

### 📊 遍历副作用节点

```
开始: nextEffect = HostRoot
     │
     ├─→ 检查 subtreeFlags & MutationMask
     │    → 有副作用，向下找第一个有副作用的节点
     │
     ├─→ nextEffect = div
     │    ├─→ 检查 subtreeFlags & MutationMask
     │    │    → 有副作用，继续向下
     │    │
     │    └─→ nextEffect = text
     │         ├─→ 检查 flags & Placement
     │         │    → 有 Placement flag！
     │         │
     │         └─→ commitPlacement(text)
     │              ├─→ getHostParent(text)
     │              │    → 向上找，找到 div
     │              │    → 返回 div.stateNode
     │              │
     │              └─→ appendPlacementNodeIntoContainer
     │                   → div.appendChild(text.stateNode)
     │
     └─→ nextEffect = div
          ├─→ 检查 flags & Placement
          │    → 没有 Placement flag（只有 subtreeFlags）
          │
          └─→ nextEffect = HostRoot
               └─→ 完成
```

**关键代码**：
```typescript
// commitWork.ts:29-35
const commitMutationEffectOnFiber = (finishedWork: FiberNode) => {
    const flags = finishedWork.flags;
    if ((flags & Placement) !== NoFlags) {
        commitPlacement(finishedWork);  // 执行插入
    }
};
```

// commitWork.ts:66-79
function appendPlacementNodeIntoContainer(finishedWork, hostParent) {
    if (finishedWork.tag === HostComponent || finishedWork.tag === HostText) {
        appendChildToContainer(hostParent, finishedWork.stateNode);
        // → parent.appendChild(child)
    } else {
        // 递归插入子节点
        appendPlacementNodeIntoContainer(child, hostParent);
    }
}

## 完整流程图总结

```
processUpdateQueue
    ↓
得到 ReactElement: <div>Hello React</div>
    ↓
reconcileChildren (创建 Fiber 树)
    ↓
workLoop (深度优先遍历)
    ├─→ beginWork (向下)
    │    ├─ HostRoot → 创建 div Fiber
    │    ├─ div → 创建 text Fiber
    │    └─ text → return null
    │
    └─→ completeWork (向上)
         ├─ text → 创建 TextNode
         ├─ div → 创建 <div>，插入 TextNode
         └─ HostRoot → 收集 flags
    ↓
commitRoot (检查副作用)
    ↓
commitMutationEffects (执行副作用)
    ├─ text → 插入到 div
    └─ div → 插入到 #root
    ↓
页面显示: "Hello React" ✅
```
