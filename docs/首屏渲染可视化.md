# 首屏渲染可视化 - ASCII 图表

## 完整流程：从 processUpdateQueue 到 DOM 渲染

### 步骤 1: processUpdateQueue - 提取 ReactElement

```
输入:
┌─────────────────────────────────────┐
│ updateQueue.shared.pending         │
│   Update {                          │
│     action: ReactElement {          │
│       type: 'div',                  │
│       props: {                      │
│         children: 'Hello React'     │
│       }                             │
│     }                               │
│   }                                 │
└─────────────────────────────────────┘

处理:
┌─────────────────────────────────────┐
│ processUpdateQueue(null, pending)   │
│   action = pending.action           │
│   action 不是函数                   │
│   → result.memorizedState = action  │
└─────────────────────────────────────┘

输出:
┌─────────────────────────────────────┐
│ workInProgress.memorizedState       │
│   ReactElement {                    │
│     type: 'div',                    │
│     props: {                        │
│       children: 'Hello React'       │
│     }                               │
│   }                                 │
└─────────────────────────────────────┘
```

---

### 步骤 2: reconcileChildren - 创建 Fiber 树

```
输入: ReactElement
┌─────────────────────────────────────┐
│ <div>Hello React</div>              │
└─────────────────────────────────────┘
           ↓ mountChildFibers
           ↓ reconcileSingleElement

输出: Fiber 树
┌─────────────────────────────────────┐
│ HostRoot Fiber                      │
│   child: ────────────────────────┐  │
└──────────────────────────────────┼──┘
                                  │
              ┌───────────────────▼──────────┐
              │ HostComponent Fiber (div)    │
              │   type: 'div'                │
              │   pendingProps: {            │
              │     children: 'Hello React'   │
              │   }                          │
              │   flags: NoFlags             │
              │   child: null                │
              └──────────────────────────────┘
```

---

### 步骤 3: workLoop - 深度优先遍历

```
遍历顺序 (向下):
┌─────────────────────────────────────────────┐
│ [1] beginWork(HostRoot)                    │
│     ├─ processUpdateQueue                   │
│     ├─ reconcileChildren                    │
│     └─ return div Fiber                     │
│                                              │
│ [2] beginWork(div)                          │
│     ├─ reconcileChildren('Hello React')     │
│     └─ return text Fiber                    │
│                                              │
│ [3] beginWork(text)                         │
│     └─ return null (叶子节点)              │
└─────────────────────────────────────────────┘

遍历顺序 (向上):
┌─────────────────────────────────────────────┐
│ [4] completeWork(text)                      │
│     ├─ createTextInstance('Hello React')    │
│     └─ stateNode = TextNode                 │
│                                              │
│ [5] completeWork(div)                      │
│     ├─ createInstance('div')                 │
│     ├─ appendAllChildren(div, text)         │
│     └─ stateNode = <div>Hello React</div>  │
│                                              │
│ [6] completeWork(HostRoot)                 │
│     └─ bubbleProperties (收集 flags)        │
└─────────────────────────────────────────────┘
```

---

### 步骤 4: completeWork - DOM 创建过程

#### 4.1 创建文本节点

```
┌─────────────────────────────────────────────┐
│ completeWork(text Fiber)                   │
├─────────────────────────────────────────────┤
│                                             │
│  createTextInstance('Hello React')         │
│      ↓                                      │
│  document.createTextNode('Hello React')    │
│      ↓                                      │
│  ┌──────────────────────┐                  │
│  │ TextNode             │                  │
│  │ data: "Hello React"  │                  │
│  └──────────────────────┘                  │
│                                             │
│  text.stateNode = TextNode                 │
└─────────────────────────────────────────────┘
```

#### 4.2 创建 div 并插入文本

```
┌─────────────────────────────────────────────┐
│ completeWork(div Fiber)                    │
├─────────────────────────────────────────────┤
│                                             │
│  1. createInstance('div', props)           │
│      ↓                                      │
│     ┌──────────┐                           │
│     │ <div>    │  (空元素)                 │
│     └──────────┘                           │
│                                             │
│  2. appendAllChildren(div, workInProgress) │
│      ↓                                      │
│     遍历子节点 (text Fiber)                │
│      ↓                                      │
│     div.appendChild(text.stateNode)        │
│      ↓                                      │
│     ┌──────────────┐                       │
│     │ <div>        │                       │
│     │   "Hello     │                       │
│     │   React"     │                       │
│     └──────────────┘                       │
│                                             │
│  3. div.stateNode = <div>Hello React</div> │
└─────────────────────────────────────────────┘
```

---

### 步骤 5: bubbleProperties - Flags 冒泡

```
冒泡过程:
┌─────────────────────────────────────────────┐
│ text Fiber                                 │
│   flags: NoFlags                           │
│   subtreeFlags: NoFlags                    │
└─────────────────────────────────────────────┘
           │
           ↓ bubbleProperties
┌─────────────────────────────────────────────┐
│ div Fiber                                  │
│   flags: NoFlags                           │
│   subtreeFlags: NoFlags                    │
│   (从 text 收集，但 text 没有 flags)       │
└─────────────────────────────────────────────┘
           │
           ↓ bubbleProperties
┌─────────────────────────────────────────────┐
│ HostRoot Fiber                             │
│   flags: NoFlags                           │
│   subtreeFlags: NoFlags                    │
└─────────────────────────────────────────────┘
```

**注意**: 在首屏渲染时，`mountChildFibers` 传入 `false`，所以不会设置 `Placement` flag。
但根节点最终会被插入到 DOM 中（通过 commitPlacement）。

---

### 步骤 6: commitRoot - 检查副作用

```
┌─────────────────────────────────────────────┐
│ commitRoot(root)                           │
├─────────────────────────────────────────────┤
│ finishedWork: HostRoot Fiber               │
│   flags: NoFlags                           │
│   subtreeFlags: NoFlags                    │
│                                             │
│ subtreeHasEffect = false                   │
│ rootHasEffect = false                      │
│                                             │
│ → 没有副作用，直接切换 current 指针        │
│   root.current = finishedWork              │
└─────────────────────────────────────────────┘
```

**注意**: 在当前实现中，首屏渲染时 flags 都是 NoFlags，所以不会执行 commitMutationEffects。
但实际上根节点需要插入到 DOM 中。这可能需要在 commitRoot 中特殊处理根节点的插入。

## 关键数据结构对比

### Fiber 树 vs DOM 树

```
Fiber 树 (内存中的数据结构):
┌─────────────────────────────────────────────┐
│ HostRoot Fiber                              │
│   stateNode: FiberRootNode                  │
│   child: ────────────────────────────────┐  │
└───────────────────────────────────────────┼──┘
                                          │
                    ┌─────────────────────▼──────────┐
                    │ HostComponent Fiber (div)      │
                    │   type: 'div'                   │
                    │   stateNode: <div>DOM</div>    │
                    │   child: ───────────────────┐  │
                    └──────────────────────────────┼──┘
                                                  │
                              ┌───────────────────▼────┐
                              │ HostText Fiber          │
                              │   stateNode: TextNode  │
                              │   child: null          │
                              └────────────────────────┘

DOM 树 (浏览器中的实际结构):
┌─────────────────────────────────────────────┐
│ <div id="root">                             │
│   ┌─────────────────────┐                  │
│   │ <div>               │                  │
│   │   "Hello React"     │                  │
│   └─────────────────────┘                  │
│ </div>                                      │
└─────────────────────────────────────────────┘
```

## 时间线图

```
时间轴 →
│
├─ [T1] processUpdateQueue
│   └─ 提取 ReactElement
│
├─ [T2] beginWork (向下遍历)
│   ├─ HostRoot → 创建 div Fiber
│   ├─ div → 创建 text Fiber
│   └─ text → return null
│
├─ [T3] completeWork (向上遍历)
│   ├─ text → 创建 TextNode
│   ├─ div → 创建 <div>，插入 TextNode
│   └─ HostRoot → 收集 flags
│
├─ [T4] commitRoot
│   └─ 检查副作用
│
└─ [T5] DOM 插入 (如果有副作用)
    └─ 插入到页面
```

## 关键函数调用链

```
processUpdateQueue
    ↓
updateHostRoot
    ↓
reconcileChildren
    ↓
mountChildFibers
    ↓
reconcileSingleElement / reconcileSingleTextNode
    ↓
placeSingleChild (设置 flags)
    ↓
workLoop
    ↓
beginWork → completeWork (循环)
    ↓
commitRoot
    ↓
commitMutationEffects (如果有副作用)
    ↓
commitPlacement
    ↓
appendChildToContainer
    ↓
parent.appendChild(child) ← 真正的 DOM 操作
```
