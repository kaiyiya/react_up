# React 渲染流程详解

## 概述

React 的渲染流程分为三个阶段：
1. **调度阶段（Schedule）** - 创建更新并调度渲染
2. **渲染阶段（Render）** - 构建 Fiber 树，计算副作用
3. **提交阶段（Commit）** - 将变更应用到 DOM

---

## 完整流程

### 第一步：初始化 - createRoot

```typescript
// test/index.tsx
const root = ReactDOM.createRoot(container);
```

**代码位置**: `packages/react-dom/src/root.ts`

```typescript
export function createRoot(container: Container) {
    const root = createContainer(container);  // 创建 FiberRootNode
    return {
        render(element: ReactElementType) {
            updateContainer(element, root);
        }
    };
}
```

**作用**：
- 创建 `FiberRootNode`（整个应用的根节点）
- 创建 `HostRoot` Fiber 节点（根 Fiber 节点）
- 初始化更新队列

**数据结构**：
```
FiberRootNode {
  container: <div id="root">,  // DOM 容器
  current: HostRootFiber,      // 当前 Fiber 树
  finishedWork: null           // 完成工作的 Fiber 树
}
```

---

### 第二步：触发更新 - render

```typescript
// test/index.tsx
root.render(React.createElement('div', {}, 'Hello React'));
```

**代码位置**: `packages/react-reconciler/src/fiberReconciler.ts`

```typescript
export function updateContainer(element: ReactElementType, root: FiberRootNode) {
    const hostRootFiber = root.current;
    const update = creatUpdate(element);           // 创建更新对象
    enqueueUpdate(hostRootFiber.updateQueue, update);  // 入队
    scheduleUpdateOnFiber(hostRootFiber);         // 调度更新
}
```

**作用**：
- 将 ReactElement 包装成 Update 对象
- 加入更新队列
- 触发调度

**Update 对象结构**：
```typescript
Update {
  action: ReactElement  // 要渲染的元素
}
```

---

### 第三步：调度渲染 - scheduleUpdateOnFiber

**代码位置**: `packages/react-reconciler/src/workLoop.ts`

```typescript
export function scheduleUpdateOnFiber(fiber: FiberNode) {
    const root = markUpdateFromFiberToRoot(fiber);  // 找到根节点
    renderRoot(root);                                // 开始渲染
}
```

**作用**：
- 从触发更新的 Fiber 向上遍历到根节点
- 调用 `renderRoot` 开始渲染流程

---

### 第四步：准备渲染 - renderRoot

**代码位置**: `packages/react-reconciler/src/workLoop.ts`

```typescript
function renderRoot(root: FiberRootNode) {
    prepareFreshStack(root);  // 初始化 workInProgress
    workLoop();               // 开始工作循环
}
```

**prepareFreshStack**：
```typescript
function prepareFreshStack(root: FiberRootNode) {
    // 创建 workInProgress 树（当前树的副本）
    workInProgress = createWorkInProgress(root.current, {});
}
```

**关键概念**：
- **current 树**：当前已渲染的 Fiber 树
- **workInProgress 树**：正在构建的新 Fiber 树
- **双缓冲机制**：两棵树交替使用，提高性能

---

### 第五步：工作循环 - workLoop

**代码位置**: `packages/react-reconciler/src/workLoop.ts`

```typescript
function workLoop() {
    while (workInProgress !== null) {
        performUnitOfWork(workInProgress);  // 处理单个 Fiber 节点
    }
}
```

**深度优先遍历**：
```
Root → Child1 → Child1.1 → Child1.2 → Child2 → ...
```

---

### 第六步：处理单元工作 - performUnitOfWork

**代码位置**: `packages/react-reconciler/src/workLoop.ts`

```typescript
function performUnitOfWork(fiber: FiberNode) {
    const next = beginWork(fiber);  // 开始工作（向下）
    fiber.memorizedPros = fiber.pendingProps;
    
    if (next == null) {
        completeUnitOfWork(fiber);  // 完成工作（向上）
    } else {
        workInProgress = next;      // 继续向下
    }
}
```

**流程**：
1. 调用 `beginWork` 处理当前节点，返回子节点
2. 如果有子节点，继续向下
3. 如果没有子节点，调用 `completeUnitOfWork` 向上回溯

---

### 第七步：开始工作 - beginWork

**代码位置**: `packages/react-reconciler/src/beginWork.ts`

```typescript
export const beginWork = (workInProgress: FiberNode) => {
    switch (workInProgress.tag) {
        case HostRoot:
            return updateHostRoot(workInProgress);      // 处理根节点
        case HostComponent:
            return updateHostComponent(workInProgress); // 处理 DOM 元素
        case HostText:
            return updateHostText();                    // 处理文本节点
    }
};
```

#### 7.1 处理根节点 - updateHostRoot

```typescript
function updateHostRoot(workInProgress: FiberNode) {
    // 1. 处理更新队列，获取最新的 state（即 ReactElement）
    const {memorizedState} = processUpdateQueue(baseState, pending);
    workInProgress.memorizedState = memorizedState;
    
    // 2. 协调子节点（对比 current 和新的 ReactElement）
    const nextChildren = workInProgress.memorizedState;
    reconcileChildren(workInProgress, nextChildren);
    
    // 3. 返回第一个子节点
    return workInProgress.child;
}
```

#### 7.2 处理 DOM 元素 - updateHostComponent

```typescript
function updateHostComponent(workInProgress: FiberNode) {
    const nextProps = workInProgress.pendingProps;
    const nextChildren = nextProps.children;  // 获取子元素
    reconcileChildren(workInProgress, nextChildren);  // 协调子节点
    return workInProgress.child;  // 返回第一个子节点
}
```

#### 7.3 协调子节点 - reconcileChildren

```typescript
function reconcileChildren(workInProgress, children) {
    const current = workInProgress.alternate;
    if (current !== null) {
        // 更新阶段：对比新旧节点
        workInProgress.child = reconcileChildFibers(...);
    } else {
        // 首屏渲染：直接创建新节点
        workInProgress.child = mountChildFibers(...);
    }
}
```

**mountChildFibers** 会：
- 根据 ReactElement 创建对应的 Fiber 节点
- 设置 Placement flag（标记需要插入 DOM）
- 建立 Fiber 树的结构关系（child, sibling, return）

---

### 第八步：完成工作 - completeUnitOfWork

**代码位置**: `packages/react-reconciler/src/workLoop.ts`

```typescript
function completeUnitOfWork(fiber: FiberNode) {
    let node: FiberNode | null = fiber;
    do {
        completeWork(node);  // 完成当前节点的工作
        
        // 处理兄弟节点
        const sibling = node.sibling;
        if (sibling !== null) {
            workInProgress = sibling;  // 转向兄弟节点
            return;
        }
        
        // 没有兄弟节点，向上回溯
        node = node.return;
        workInProgress = node;
    } while (node !== null);
}
```

**回溯过程**：
```
Child1.2 (完成) → Child1 (完成) → Root (完成)
```

---

### 第九步：完成工作 - completeWork

**代码位置**: `packages/react-reconciler/src/completeWork.ts`

```typescript
export const completeWork = (workInProgress: FiberNode) => {
    switch (workInProgress.tag) {
        case HostComponent:
            // 首屏渲染：创建 DOM 元素
            const instance = createInstance(workInProgress.type, newProps);
            // 将子节点插入到当前 DOM 元素
            appendAllChildren(instance, workInProgress);
            workInProgress.stateNode = instance;  // 保存 DOM 引用
            break;
            
        case HostText:
            // 创建文本节点
            const instance = createTextInstance(newProps.content);
            workInProgress.stateNode = instance;
            break;
    }
    
    // 收集 flags，冒泡到父节点
    bubbleProperties(workInProgress);
};
```

**关键操作**：
1. **createInstance**：创建 DOM 元素（如 `<div>`）
2. **appendAllChildren**：将子节点的 DOM 插入到当前元素
3. **bubbleProperties**：将子节点的 flags 冒泡到父节点

**注意**：此时 DOM 元素已创建，但**还未插入到页面**！

---

### 第十步：提交阶段 - commitRoot

**代码位置**: `packages/react-reconciler/src/workLoop.ts`

当 `workLoop` 完成后，需要调用 `commitRoot`（代码中应该在 `renderRoot` 后调用）

```typescript
function commitRoot(root: FiberRootNode) {
    const finishedWork = root.finishedWork;
    
    // 检查是否有副作用需要执行
    const subtreeHasEffect = (finishedWork.subtreeFlags & MutationMask) !== NoFlags;
    const rootHasEffect = (finishedWork.flags & MutationMask) !== NoFlags;
    
    if (subtreeHasEffect || rootHasEffect) {
        // Mutation 阶段：执行 DOM 操作
        commitMutationEffects(finishedWork);
        
        // 切换 current 指针
        root.current = finishedWork;
    }
}
```

---

### 第十一步：提交副作用 - commitMutationEffects

**代码位置**: `packages/react-reconciler/src/commitWork.ts`

```typescript
export const commitMutationEffects = (finishedWork: FiberNode) => {
    nextEffect = finishedWork;
    while (nextEffect !== null) {
        // 向下找到第一个有副作用的节点
        const child = nextEffect.child;
        if (hasEffect && child !== null) {
            nextEffect = child;
        } else {
            // 处理当前节点
            commitMutationEffectOnFiber(nextEffect);
            // 处理兄弟节点
            // 向上回溯
        }
    }
};
```

---

### 第十二步：提交 Placement - commitPlacement

**代码位置**: `packages/react-reconciler/src/commitWork.ts`

```typescript
const commitPlacement = (finishedWork: FiberNode) => {
    // 1. 找到父容器（DOM 元素）
    const hostParent = getHostParent(finishedWork);
    
    // 2. 将 DOM 节点插入到容器中
    if (hostParent !== null) {
        appendPlacementNodeIntoContainer(finishedWork, hostParent);
    }
};
```

**appendPlacementNodeIntoContainer**：
```typescript
function appendPlacementNodeIntoContainer(finishedWork, hostParent) {
    if (finishedWork.tag === HostComponent || finishedWork.tag === HostText) {
        // 直接插入 DOM 节点
        appendChildToContainer(hostParent, finishedWork.stateNode);
    } else {
        // 递归插入子节点
        appendPlacementNodeIntoContainer(child, hostParent);
    }
}
```

**最终操作**：
```typescript
// react-dom/src/hostConfig.ts
export const appendChildToContainer = (child, parent) => {
    parent.appendChild(child);  // 真正的 DOM 操作！
};
```

## 关键概念总结

### 1. 双缓冲机制
- **current 树**：当前显示的 Fiber 树
- **workInProgress 树**：正在构建的新 Fiber 树
- 渲染完成后，两棵树交换

### 2. 深度优先遍历
- **向下**：beginWork（处理节点，创建子节点）
- **向上**：completeWork（完成节点，创建 DOM）

### 3. 三个阶段
- **Schedule**：调度更新
- **Render**：构建 Fiber 树，计算副作用（可中断）
- **Commit**：应用变更到 DOM（不可中断）

### 4. Flags 系统
- **Placement**：需要插入 DOM
- **Update**：需要更新属性
- **Deletion**：需要删除节点
- Flags 会从子节点冒泡到父节点

### 5. 副作用收集
- 在 `completeWork` 中收集 flags
- 在 `commitMutationEffects` 中执行副作用
- 确保 DOM 操作批量执行，提高性能

---

## 示例：渲染 `<div>Hello React</div>`

1. **createRoot** → 创建 FiberRootNode
2. **render** → 创建 Update { action: ReactElement }
3. **beginWork(HostRoot)** → 处理根节点，创建子 Fiber
4. **beginWork(HostComponent)** → 处理 div，创建文本 Fiber
5. **beginWork(HostText)** → 处理文本，返回 null
6. **completeWork(HostText)** → 创建文本节点 "Hello React"
7. **completeWork(HostComponent)** → 创建 div，插入文本节点
8. **completeWork(HostRoot)** → 完成根节点
9. **commitPlacement** → 将 div 插入到 #root
10. **页面显示** → "Hello React"

---

这就是 React 的完整渲染流程！🎉
