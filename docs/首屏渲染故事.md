# 一个 ReactElement 的奇幻之旅：从代码到屏幕的完整故事

## 第一章：诞生 - ReactElement 的创建

在一个阳光明媚的早晨，开发者小明在代码中写下了这样一行：

```typescript
const element = React.createElement('div', {}, 'Hello React');
```

**"我诞生了！"** 一个 ReactElement 兴奋地说道。它看了看自己：

```javascript
{
  $$typeof: Symbol.for('react.element'),
  type: 'div',
  props: {
    children: 'Hello React'
  },
  key: null,
  ref: null,
  __mark: 'zll'
}
```

"我的类型是 'div'，我有一个文本子元素 'Hello React'。但我还只是一个普通的 JavaScript 对象，还没有任何超能力。" ReactElement 自言自语道。

## 第六章：工作循环 - workLoop 的深度优先遍历

**"欢迎来到工作循环！"** `workLoop` 函数说道。

```typescript
function workLoop() {
    while (workInProgress !== null) {
        performUnitOfWork(workInProgress);  // 处理单个工作单元
    }
}
```

这是一个**深度优先遍历**的过程，就像探索一棵树：

```
开始: workInProgress = HostRoot
     │
     ├─→ 向下：beginWork (处理节点，创建子节点)
     │
     └─→ 向上：completeWork (完成节点，创建 DOM)
```

**"我们要用深度优先的方式遍历整棵树！"** workInProgress 解释道。

```typescript
function bubbleProperties(workInProgress: FiberNode) {
```

## 第九章：提交阶段 - commitRoot 的检查

**"现在进入提交阶段！"** `commitRoot` 说道。

```typescript
function commitRoot(root: FiberRootNode) {
    const finishedWork = root.finishedWork;
    
    // 判断是否存在副作用需要执行
    const subtreeHasEffect = (finishedWork.subtreeFlags & MutationMask) !== NoFlags;
    const rootHasEffect = (finishedWork.flags & MutationMask) !== NoFlags;
    
    if (subtreeHasEffect || rootHasEffect) {
        // Mutation 阶段：执行 DOM 操作
        commitMutationEffects(finishedWork);
        root.current = finishedWork;  // 切换 current 指针
    } else {
        root.current = finishedWork;  // 直接切换（没有副作用）
    }
}
```

**"检查一下... subtreeFlags 是 NoFlags，flags 也是 NoFlags。"** `commitRoot` 检查道。

**"没有副作用需要执行，直接切换 current 指针。"** `commitRoot` 说道。


```typescript
    while (nextEffect !== null) {
```

```typescript
function getHostParent(fiber: FiberNode): Container {
    let parent = fiber.return;  // 向上找父节点
    
    while (parent) {
        if (parent.tag === HostComponent) {
            return parent.stateNode;  // 返回 DOM 元素
        }
        if (parent.tag === HostRoot) {
            return (parent.stateNode as FiberRootNode).container;  // 返回容器
        }
        parent = parent.return;
    }
    
    throw new Error('未找到 host parent');
}
```

## 后记：关键概念总结

### 1. 双缓冲机制
- **current 树**：当前显示的 Fiber 树
- **workInProgress 树**：正在构建的新 Fiber 树
- 渲染完成后，两棵树交换

### 2. 深度优先遍历
- **向下**：beginWork（处理节点，创建子节点）
- **向上**：completeWork（完成节点，创建 DOM）

### 3. 三个阶段
- **Schedule**：调度更新（updateContainer → scheduleUpdateOnFiber）
- **Render**：构建 Fiber 树，计算副作用（workLoop → beginWork → completeWork）
- **Commit**：应用变更到 DOM（commitRoot → commitMutationEffects → commitPlacement）

### 4. 关键数据结构
- **ReactElement**：描述 UI 的 JavaScript 对象
- **Fiber 节点**：工作单元，包含节点信息和副作用标记
- **DOM 节点**：浏览器中的真实元素

### 5. 更新队列
- **Update**：更新对象，包含 action（ReactElement 或函数）
- **UpdateQueue**：更新队列，存储待处理的更新
- **processUpdateQueue**：处理更新，计算新的状态
